# Правила игнорирования файлов в .gitignore Terraform

В этом разделе объяснено, какие файлы и папки будут игнорироваться Git согласно правилам из `.gitignore`, используя язык правил gitignore.

- `*.tfstate`  

  Игнорируются все файлы, где имя заканчивается на `.tfstate`.  
  *`*` — любой набор символов (в том числе пустой)*.  
  Пример: `terraform.tfstate`, `prod.tfstate`.

- `*.tfstate.*`  

  Игнорируются файлы, у которых есть расширение вида `.tfstate.*` (например, `.tfstate.backup`).  
  Пример: `terraform.tfstate.backup`.

- `.terraform/`  

  Игнорируется папка `.terraform` вместе со всем её содержимым.  
  *Слеш `/` в конце обозначает, что это директория*.

- `*.backup`  

  Игнорируются все файлы с расширением `.backup`.  
  Пример: `main.tf.backup`.

- `*_IGNORE_*`  

  Игнорируются все файлы и папки, в имени которых **встречается последовательность символов "IGNORE"** с любыми символами (или их отсутствием) слева и справа.  
  *`*` означает любые символы (или отсутствие символов)*.  
  Примеры: `file_IGNORE_name.txt`, `IGNORE_test.tf`, `myIGNOREfile`.

- `*.log`  

  Игнорируются файлы с расширением `.log`.  
  Пример: `error.log`.

---

**Важно**

- Символ `*` соответствует любой последовательности символов (в том числе пустой).
- Правила применяются к имени файла или папки целиком.
- Обратите внимание на `/` в конце правила — это указывает, что правило применяется к папке.
